## 快速开始

### 第一步：下载客户端

1. iOS 用户
   - 切换至美区 App Store
   - 搜索下载 "Stash" 应用
   - 首次使用需要允许 VPN 配置权限

2. 安卓用户
   - 访问官方网站下载 APK
   - 开启"允许安装未知来源应用"
   - 完成安装

3. Windows/MacOS 用户
   - 访问官方网站下载对应系统版本
   - 按照安装向导完成安装
   - 首次运行可能需要授予管理员权限

### 第二步：导入配置

1. 打开 Stash App
2. 点击底部的**设置**标签
3. 点击最上方的**配置文件**
4. 选择**从文件导入**
5. 找到并选择配置文件
6. 点击**确认导入**

### 第三步：开始使用

1. 返回首页
2. 点击右上方**开始**按钮启动服务
3. 首次使用会请求 VPN 权限，请点击允许
4. 等待连接成功提示

## 进阶配置

### 自定义配置文件

如需修改配置文件，请按以下步骤操作：

1. 打开配置文件（base.yaml）
2. 在 `proxies` 部分更新节点信息：
```yaml
proxies:
  - name: "USA-Node1"
    type: trojan
    server: your-server-address
    port: your-port
    password: your-password
```

3. 在 `proxy-groups` 部分更新节点引用：
```yaml
proxy-groups:
  - name: USA
    type: select
    proxies:
      - USA-Node1
  - name: USA_Auto
    type: url-test
    proxies:
      - USA-Node1
```

### 性能优化

1. **选择最佳节点**
   - 点击**策略**标签
   - 选择 USA_Auto 组
   - 系统会自动测试并选择最佳节点

2. **手动测速**
   - 点击任意节点右侧的刷新图标
   - 等待测速完成
   - 选择延迟最低的节点

3. **定期更新配置**
   - 建议每月更新一次配置文件
   - 及时获取最新节点信息
   - 保持最佳使用体验

## 常见问题解答

### 连接问题

1. **无法连接怎么办？**
   - 检查网络连接是否正常
   - 确认配置文件是否正确导入
   - 尝试切换不同节点
   - 重启应用后重试

2. **连接速度慢怎么办？**
   - 切换到 USA_Auto 模式
   - 手动测试各节点延迟
   - 选择延迟最低的节点
   - 避开高峰时段使用

3. **经常断开连接怎么办？**
   - 检查本地网络稳定性
   - 更新至最新版本客户端
   - 尝试更换节点
   - 联系技术支持处理

### 配置问题

1. **导入配置失败？**
   - 检查配置文件格式是否正确
   - 确认 yaml 语法无误
   - 尝试重新下载配置文件
   - 清除应用数据后重试

2. **配置文件过期？**
   - 联系客服获取最新配置
   - 按照指引更新节点信息
   - 重新导入更新后的配置

## 使用建议
